# e-Request
Electronic Request for Information from A Thai Governmental Organization

## เทคนิคการพัฒนา
- ในปี 65 มีกฎหมายใหม่ออกมาฉบับหนึ่ง คือ พ.ร.บ. การปฏิบัติราชการทางอิเล็กทรอนิกส์ ซึ่งอนุญาตให้ประชาชนสามารถติดต่อราชการ ยื่นคำขอต่าง ๆ ผ่านช่องางอิเล็กทรอนิกส์ของหน่วยงาน
- ต่อมาทุกหน่วยงานก็ประกาศช่องทางอิเล็กทรอนิกส์ ให้ประชาชนใช้ติดต่อราชการหรือยื่นคำขอทางอีเมลกลางของแต่ละหน่วยงาน
- กองกลาง เห็นว่า เรื่องนี้มีความเสี่ยง 2 ประการ ซึ่งจะเป็นปัญหาในทางปฏิบัติ หากมีประชาชนยื่นคำขอข้อมูลข่าวสารของราชการทางอีเมล คือ
  1. แจ้งรายละเอียดไม่ครบถ้วน ตามคำขอ ทำให้พิจารณาไมได้ ต้องขอข้อมูลเพิ่มเติม
  2. ประชาชนร่างหนังสือราชการไม่เป็น มีรูปแบบไม่เป็นไปในทิศทางงเดียวกัน เพราะอีเมลเป็น blank form
  3. ประชาชนไม่ทราบช่องทางติดต่อราชการของหน่วยงานในกระทรวง หรือทราบแต่จำไม่ได้ หรือกรอกผิด ทำให้คำขอไม่ถูกส่งไปยังหน่วยงานเป้าหมาย

ในปี 67 สป.ทส. ร่วมกับทุกหน่วยงานใน ทส. จึงจัดทำโครงการ e-Request ขึ้นมา เพื่อ ช่วยประชาชนในการเขียนอีเมล เพื่อขอข้อมูลข่าวสาร
