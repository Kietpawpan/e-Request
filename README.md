# e-Request
Electronic Request for Information from A Thai Governmental Organization

## เทคนิคการพัฒนา
- ปี 65 มีกฎหมายใหม่ออกมาฉบับหนึ่ง คือ พ.ร.บ. การปฏิบัติราชการทางอิเล็กทรอนิกส์ ซึ่งอนุญาตให้ประชาชนสามารถติดต่อราชการ ยื่นคำขอทุกเรื่อง ผ่านช่องทางอิเล็กทรอนิกส์ของหน่วยงานได้
- ต่อมาทุกหน่วยงานต้องประกาศช่องทางอิเล็กทรอนิกส์ โดยให้ประชาชนใช้ติดต่อหรือยื่นคำขอทางอีเมล
- ทีมงานติดตามศึกษากฎหมายฉบับนี้ เห็นว่า เรื่องนี้มีความเสี่ยง 2 ประการ ซึ่งจะเป็นปัญหาในทางปฏิบัติ หากมีประชาชนยื่นคำขอข้อมูลข่าวสารของราชการทางอีเมล คือ
  1. แจ้งรายละเอียดไม่ครบถ้วน ทำให้พิจารณาไมได้ ต้องขอข้อมูลเพิ่มเติม เสียเวลาทั้งผู้ขอและผู้ให้บริการ
  2. ประชาชนร่างหนังสือราชการไม่เป็น มีรูปแบบไม่เป็นไปในทิศทางงเดียวกัน เพราะอีเมลเป็น blank form 
  3. ประชาชนไม่ทราบช่องทางติดต่อราชการของหน่วยงานในกระทรวง หรือทราบแต่จำไม่ได้ หรือกรอกผิด ทำให้คำขอไม่ถูกส่งไปยังหน่วยงานเป้าหมาย

ในปี 67 สป.ทส. จึงร่วมทุกหน่วยงานใน ทส. จัดทำโครงการ e-Request ขึ้นมา เพื่อ ช่วยประชาชนในการเขียนอีเมล เพื่อขอข้อมูลข่าวสาร โดย
1. มี e-From ให้ประชาชนกรอกข้อมูลอย่างครบถ้วน
2. มีระบบสร้างคำขอ โดยช่วยร่าง พิมพ์คำขอเป็นภาษาราชการ พร้อมกำหนดอีเมลของแต่ละหน่วยงาน พร้อมส่ง
3. มีระบบติดตามสถานะคำขอ ติดตามเรื่องด้วยหมายเลขประชาชน ภายใน 24 ชม.

## ความรู้
1. การออกแบบบริการดิจิทัล TDGA
2. ภาษาสำหรับพัฒนา web application เป็น javaScript ระดับพื้นฐาน
3. มาตการการพัฒนา app ภาครัฐ ของ DGA
4. การคุมครองข้อมูลส่วนบุคคลด้วย Secure Hash Algorithm 512 บิท
